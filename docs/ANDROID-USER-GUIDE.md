## 문서 기준

USB로 연결된 삼성 SM-G960N(Android 10)에서 DEPL 화면을 직접 캡처했습니다. 이미지 합성이나 앱 UI 변경 없이 사용합니다. 화면은 설치본 기준, 저장 동작은 현재 저장소 소스 기준입니다. Android 버전·제조사·설치된 앱 버전에 따라 화면과 메뉴가 다를 수 있습니다.

이번 문서 작업에서는 새 QR 등록, 테스트 Push 발송, 기존 등록 초기화 또는 알림 삭제를 실행하지 않습니다. 기존 화면을 관찰하고 사용 절차를 설명합니다.

|---|---|
| [메인·알림 내역](assets/android-guide/01-main-history.png) | 설정 접힘, 저장된 알림 3건 |
| [알림 설정](assets/android-guide/02-notification-settings.png) | 앱 표기: 알림 권한 허용, 배터리 최적화 사용 중 |

화면 원본은 Android의 `screencap`으로 저장했습니다. 가이드에 기기 일련번호·토큰·유효한 QR 원문을 넣지 않았으며, 등록 완료 팝업은 직접 촬영하지 않고 현재 소스의 안내 문구를 설명했습니다.

## 1. 시작하기

회사에서 배포한 DEPL 앱을 설치하고 휴대폰의 Wi-Fi 또는 이동통신 연결을 확인하세요. 앱은 Firebase를 이용하며 업무망 Gateway에 직접 접속하지 않습니다.

메인 화면의 ‘알림 설정’을 누르면 상태 카드가 펼쳐집니다. 다시 누르면 접힙니다. QR 등록 버튼과 알림 내역은 그 아래에 있습니다.

## 2. 알림 설정 확인

- 알림 권한: Android 13 이상에서는 최초 권한 요청이 나오면 허용합니다. 캡처 기기는 Android 10이라 같은 권한 팝업이 나타나지 않습니다. 실제 알림 허용 여부는 시스템 앱 알림 설정에서도 확인하세요.
- 배터리 최적화: 상태가 ‘사용 중’이면 ‘배터리 최적화 제외’를 눌러 시스템 안내를 확인하고 사용자가 허용 여부를 선택합니다. 현재 상태가 ‘제외됨’이면 다시 설정할 필요가 없습니다.
- 잠금 화면·팝업: ‘잠금 화면 · 팝업 설정’은 시스템 알림 설정을 엽니다. 잠금 화면 내용 표시, 소리·진동, 알림 채널 설정을 확인합니다. 화면이 켜지는 방식과 팝업 모양은 제조사·OS 정책에 따라 다릅니다.
- 무음·방해 금지·절전 설정으로 알림 표시나 소리가 달라질 수 있습니다. 앱에 ‘허용’이 보여도 모든 시스템 설정이 정상임을 보장하는 것은 아닙니다.

설정 확인만 할 때는 값을 바꾸거나 권한을 다시 승인할 필요가 없습니다.

## 3. QR로 기기 등록

1. 업무 시스템에서 본인 사용자와 실제 소속 부서의 최신 등록 QR을 표시합니다.
2. DEPL에서 ‘QR로 기기 등록’을 누릅니다.
3. 카메라 사용 권한이 필요하면 허용합니다.
4. QR 전체가 카메라에 보이도록 맞추고 검증·구독 처리를 기다립니다.
5. ‘기기 등록 완료’ 안내와 ‘개인 · 부서 · 공지 알림을 받을 준비가 되었습니다.’ 문구를 확인하고 ‘확인’을 누릅니다.
6. 메인 화면에서 상태를 확인한 뒤 관리자에게 본인 대상 테스트 알림을 요청합니다. 시스템 알림과 DEPL 내부 내역을 각각 확인하세요.

QR은 기본 3분, 최대 10분 유효하며 회사 발급 설정에 따라 달라질 수 있습니다. 만료되면 업무 시스템에서 재발급받으세요. 다른 사람의 QR을 사용하거나 QR 이미지·원문을 공유하지 않습니다. 오류가 계속되면 회사 앱과 회사 QR의 조합을 관리자에게 확인하세요.

## 4. 알림 내역 확인

메인 화면 ‘알림 내역’에서 최신순으로 문구와 기록 시각을 확인합니다. 오른쪽 숫자는 저장된 목록 개수이며 스크롤하면 이전 내역을 볼 수 있습니다. 업무 상세 화면을 여는 기능은 없으므로 실제 업무 처리는 기존 업무 시스템에서 진행합니다.

현재 소스는 기기 DB(Room)에 최신 3,000건을 보관하고 30건 단위로 목록을 읽습니다. 30은 목록 읽기 단위이지 보관 상한이 아닙니다. 같은 eventId는 중복 저장하지 않으며, 초과분은 오래된 순서로 정리합니다. 같은 문구라도 다른 eventId이면 별도 알림입니다.

앱의 메시지 수신 처리가 실행되면 유효한 알림을 DB에 저장한 후 시스템 알림을 표시합니다. 모든 Push의 전달·저장을 보장하는 것은 아닙니다. 네트워크, 앱 강제 종료, OS·제조사 절전 정책 등의 영향을 받을 수 있으며 서버 내역을 다시 내려받아 복원하는 기능은 없습니다.

## 5. 삭제와 초기화 구분

| 기능 | 영향 |
|---|---|
| 알림 내역 우측 휴지통 | 확인 창 승인 후 기기에 저장된 알림 내역 전체 삭제. 단순 새로고침이 아니며 서버에서 복원되지 않음 |
| 기기 등록 초기화 | 확인 창 승인 후 기존 알림 구독 해제. 이후 새 QR 등록 필요 |

부서 변경·기기 변경 시 관리자에게 새 QR을 요청합니다. 오류 확인이나 문서 캡처 목적으로 위 버튼을 실행하지 마세요. 앱 삭제 또는 앱 데이터 삭제 전에도 관리자에게 복구 가능 여부를 문의하세요.

## 6. 문제 해결

| 증상 | 확인할 사항 |
|---|---|
| 카메라 화면이 안 보임 | 시스템 설정에서 DEPL 카메라 권한 확인 |
| QR 만료 | 업무 시스템에서 최신 QR 재발급 |
| QR 서명·프로젝트 오류 | 올바른 회사 앱과 QR인지 확인 후 관리자 문의 |
| 등록 중 멈춤·등록 실패 | 인터넷 연결 확인 후 재시도. 오류 문구와 발생 시각 기록 |
| 알림·진동·소리가 안 남 | 시스템 앱 알림, 채널, 잠금 화면, 무음·방해 금지 상태 확인 |
| 잠금 상태에서 알림 지연 | 배터리 최적화, 제조사 절전 정책과 인터넷 연결 확인 |
| 알림 내역이 비어 있음 | 기기 등록 상태, 삭제 여부, 실제 수신 여부 확인. 관리자와 테스트 |

문의 시 앱 버전·OS 버전·발생 시각·오류 문구를 전달합니다. QR 원문·FCM 토큰·개인키·민감한 업무 내용은 전달하지 마세요.
