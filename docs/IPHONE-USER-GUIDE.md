# DEPL iPhone 사용자 가이드

작성일: 2026-09-10. 대상: QR 기기 등록 및 앱 내부 알림 내역 확인.
실제 연결된 iPhone 15 Pro의 DEPL 화면을 사용합니다. 화면 캡처는 설치된 앱 기준이며 저장 동작 설명은 현재 저장소 소스 기준입니다. 설치 버전에 따라 화면이나 동작이 다를 수 있습니다.

## 1. 사용 전 준비

회사에서 배포한 DEPL 앱을 설치하고 iPhone의 인터넷 연결(Wi-Fi 또는 이동통신)을 확인합니다. 회사 업무 시스템에서 본인용 등록 QR을 발급받습니다. 앱은 업무망 Gateway에 직접 접속하지 않습니다.

최초 실행 시 알림 권한을 허용합니다. 이미 거부했다면 iPhone 설정에서 DEPL의 알림 허용을 켭니다. 소리, 잠금 화면 표시, 집중 모드, 무음 설정은 별도이므로 앱 내 내역이 있다고 항상 소리가 나는 것은 아닙니다.

## 2. 메인 화면 읽기

- 상단 상태 카드: 알림 준비 상태와 알림 권한을 보여줍니다.
- ‘알림 설정을 확인하고 있습니다.’는 확인 중 상태입니다. 등록 완료를 뜻하지 않습니다.
- ‘QR로 기기 등록’: 본인·부서·전체 공지 알림 연결 화면을 엽니다.
- ‘알림 내역’: 이 앱이 기기에 저장한 알림과 저장 시각을 보여줍니다. 우측 숫자는 저장된 목록 개수입니다.

‘알림 권한 · 허용’은 iPhone의 표시 권한이며 개인·부서·공지 구독 완료와 별개입니다. 기기 등록 화면에서 세 항목의 상태도 확인하세요.

## 3. QR로 기기 등록

1. 업무 시스템에서 본인 사용자와 실제 소속 부서의 최신 QR을 표시합니다. QR은 비밀번호처럼 공유하지 마세요.
2. DEPL 메인 화면에서 ‘QR로 기기 등록’을 누릅니다.
3. 카메라 권한 요청이 나오면 촬영을 위해 허용합니다.
4. 업무 화면의 QR 전체가 카메라 테두리 안에 들어오도록 맞추고 검증·연결을 기다립니다.
5. ‘기기 등록이 완료되었습니다.’와 개인 알림·부서 알림·전체 공지의 성공 상태를 확인합니다. 하나라도 실패하면 완료로 판단하지 마세요.
6. 닫기 버튼으로 메인 화면으로 돌아가 관리자에게 본인 대상 테스트 알림을 요청합니다.

QR 유효시간은 발급 설정에 따릅니다(현재 기본 3분, 최대 10분). 만료되면 새 QR을 발급받으세요. 기기 시간은 자동 설정을 사용하는 것이 좋습니다. 개발용 빌드에 ‘DEBUG · QR 문자열 테스트’가 보여도 일반 사용자는 입력할 필요가 없습니다.

## 4. 알림 내역 확인

메인 화면의 ‘알림 내역’에서 최신 항목부터 확인하고 위아래로 스크롤합니다. 앱은 Gateway에서 보낸 알림 문구를 보여주며 업무 상세 페이지를 여는 기능은 없습니다. 상세 업무는 기존 업무 시스템에서 확인하세요.

현재 소스의 최대 보관 개수는 3,000건이며 초과 시 오래된 항목을 제외합니다. 동일 eventId는 중복 저장하지 않습니다. 화면을 아래로 당기는 새로고침은 로컬 내역을 읽는 동작입니다. Gateway에서 과거 내역을 다시 내려받지 않습니다.

중요: iPhone 잠금 화면에 표시된 알림과 DEPL 내부 저장 내역은 별개입니다. 앱이 화면에 열린 동안 수신하거나 알림을 눌러 처리된 경우 저장되지만, 백그라운드·종료 상태의 모든 수신 내역을 저장하는 것은 보장하지 않습니다. 목록에 없다고 전송되지 않았다고 단정하지 마세요. 앱 삭제 전 로컬 내역 복구가 필요하면 관리자에게 먼저 문의하세요.

## 5. 문제가 생겼을 때

| 증상 | 사용자가 확인할 것 |
|---|---|
| QR 촬영 화면이 안 보임 | iPhone 설정에서 DEPL의 카메라 권한 확인 |
| 유효시간 만료 | 업무 시스템에서 QR 재발급 후 다시 촬영 |
| 다른 시스템 QR / 서명 오류 | 회사 앱과 회사 시스템 QR이 맞는지 확인 후 관리자에게 문의 |
| 구독 실패 / 일부 항목만 성공 | 인터넷 연결 확인 후 다시 시도. 반복되면 관리자에게 문의 |
| 알림 준비 상태가 계속 확인 중 | 인터넷 연결과 회사 앱 버전 확인 후 관리자에게 상태 문구 전달 |
| 알림이 안 보이거나 소리가 안 남 | 알림 허용, 잠금 화면, 집중 모드·무음 설정 및 세 항목 등록 상태 확인 |
| 알림은 왔는데 앱 내역에 없음 | 현재 iOS 저장 방식의 제한일 수 있음. 앱을 열거나 해당 알림을 눌러 확인 |

부서 변경·기기 변경 시에는 관리자에게 새 QR 발급을 요청합니다. ‘기기 등록 초기화’는 기존 구독을 해제하는 기능입니다. 캡처나 단순 오류 확인 목적으로 누르지 마세요. 구독 해제 후에는 새 QR로 등록해야 알림을 계속 받을 수 있습니다.

문의할 때는 앱 버전, 발생 시각, 오류 문구, 등록 항목별 상태를 전달합니다. QR 원문·QR 이미지·FCM 토큰·개인키는 보내지 않습니다.
